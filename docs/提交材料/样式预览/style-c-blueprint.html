④关键约束

  • 客户端只访问 Gateway，不直连业务端口
  • 权限服务端二次校验，不信任前端状态
  • 写操作携带 version，冲突返回 409
  • 数据按家庭隔离，跨家庭 404 / 403
LEGEND
实线＝已接入真实数据；虚线＝领域边界已定、尚未接入业务。响应统一 code / message / data / traceId。
