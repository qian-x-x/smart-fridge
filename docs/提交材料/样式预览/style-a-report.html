③服务清单（摘要）

服务端口职责状态
gateway-service8080唯一入口 · 鉴权 · 路由 · 追踪已实现
auth-family-service8081账号 · 令牌 · 家庭与成员治理已实现
fridge-service8082冰箱结构 · 食材 · 操作流水已实现
recipe-service8083菜谱目录 · 原料 · 步骤已实现
stock / order / notification8084-86库存 · 订单 · 通知领域边界骨架

④关键约束

  • 客户端只访问 Gateway，不直连 8081–8086
  • 权限在服务端二次校验，不依赖前端按钮状态
  • 写操作携带 version，冲突返回 409 并提示刷新
  • 数据按家庭隔离，跨家庭一律 404 / 403
