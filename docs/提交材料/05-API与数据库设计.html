接口契约、权限要求与数据表结构

接口清单 · 统一前缀 /api/v1，响应 code / message / data / traceId

方法路径说明权限
认证
POST/auth/register注册并直接返回令牌公开
POST/auth/login账号或手机号 + 密码登录公开
POST/auth/refresh刷新令牌，旧 refresh 立即作废持 refresh
POST/auth/logoutaccess 加入黑名单、refresh 撤销登录用户
家庭
GET POST/families我的家庭列表 / 创建家庭（创建者即 OWNER）登录用户
POST/families/join8 位邀请码加入，默认 VIEWER，重复加入幂等登录用户
GET/families/{id}家庭详情，返回当前用户角色（服务间鉴权用）家庭成员
GET PATCH/families/{id}/members成员列表 / 调整 EDITOR、VIEWEROWNER
POST/families/{id}/transfer-owner转交所有权，原 OWNER 降为 EDITOROWNER
冰箱与食材
POST GET/fridges创建冰箱并生成四区 / 按 familyId 查冰箱OWNER · 成员
GET/foods?fridgeId&query&category&tags&zoneId&expiryState&sort组合筛选与四种排序，默认到期升序家庭成员
POST/foods新增食材，校验分区与容器归属OWNER / EDITOR
PUT DELETE/foods/{id}整体编辑 / 软删除，均需携带 versionOWNER / EDITOR
POST/foods/{id}/move · /consume移动分区 / 按量扣减，超额返回 409OWNER / EDITOR
菜谱
GET/recipes · /recipes/{id}菜谱目录与详情（含原料、步骤）登录用户

数据库设计 · MySQL 8 / Flyway 版本化

app_user

id · username（唯一）· phone（唯一）· password_hash · display_name · status
密码 BCrypt，用户名与手机号至少填一项

family

id · name · invite_code（唯一）· owner_user_id
一家庭一冰箱，由 uk_fridge_family 约束

family_member

family_id · user_id · role · joined_at
(family_id, user_id) 唯一，role ∈ OWNER/EDITOR/VIEWER

refresh_session

token_id · user_id · expires_at · revoked
消费即失效，支撑一次性轮换

fridge · fridge_zone · fridge_container

fridge(family_id, name, timezone) · zone(code, name, temperature_c) · container(zone_id, name, type)
建冰箱自动生成 FRESH / VARIABLE / FREEZER / PANTRY

food_item

fridge_id · zone_id · container_id · name · category · quantity · unit · production_date · expires_on · tags · version · status
version 乐观锁；quantity ≥ 0；软删置 DISCARDED

food_operation

food_item_id · actor_user_id · action · old/new 分区、容器、数量 · original_operation_id
只追加不删除，original 字段为撤销预留

recipe · recipe_ingredient

recipe(name, steps, featured) · ingredient(recipe_id, name, quantity, unit, optional)
步骤以 | 分隔存储，读取时拆分为列表
核心表
所有业务表按 family_id / fridge_id 做逻辑隔离
