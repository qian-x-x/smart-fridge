## 规格

- 画布 1600 × 1000 px，PNG，可直接插图或用 A4 横向打印。
- 视觉：草稿纸底 + 手绘抖动边框 + 楷体标题，黑白为主、陶土橙仅用于高亮。
- 版式只保留标题与正文内容，不含页眉说明、页脚与总结条。
- 内容全部取自本仓库真实实现，未使用占位数据。

## 源文件与再生成

同目录 `.html` 为源文件，共用 `sketch.css`（含手绘边框的 SVG 抖动滤镜、便签、检查清单、调用链等组件）。修改文案后重新截图即可：

```powershell
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
& $edge --headless=new --disable-gpu --hide-scrollbars `
  --force-device-scale-factor=1 --window-size=1600,1000 `
  --screenshot="01-功能架构图.png" "01-功能架构图.html"
```

`样式预览/` 是选定视觉方向前的三套配色样张，保留作选型记录，不参与提交。
