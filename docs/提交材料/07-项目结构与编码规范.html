编码规范 · 六条硬规则

命名NAMING

服务名 域-职责-service；Java 包 com.smartfridge.域.层；Dart 文件 snake_case、类 UpperCamel；接口路径用复数资源 + kebab-case。

分层LAYERING

控制器只做参数校验与 HTTP 映射；业务规则写在应用服务；仓储只写 SQL 与映射。跨层调用倒置视为严重缺陷。

响应与异常RESPONSE

统一 code / message / data / traceId；业务错误抛 BusinessException，参数错 400、未登录 401、越权 403、冲突 409，不把异常抛成 500。

数据库DATABASE

只用 Flyway 迁移，已发布脚本不得修改；表名列名 snake_case；每张表须包含审计时间字段；所有写操作必须携带并校验 version。

提交与审查REVIEW

提交信息 type(scope): 主题；每个阶段结束需在 docs/reviews/ 记录审查结论并更新开发状态；main 分支保持可编译。

协作底线BASELINE

密钥、真实用户图片与未授权素材不入库；中间件必须随真实业务接入，不后补静态声明；数据库结构只经 Flyway 变更。
