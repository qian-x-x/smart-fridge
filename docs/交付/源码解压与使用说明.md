归档日期：2026-11-10。格式为 ZIP，默认文件名为 `小易冰箱-源码-20261110.zip`，解压后统一放在 `xiaoyi-fridge/` 目录中。

这是一份当前工作区源码快照，包含最新未提交改动；清单中的 `gitBaseCommit` 只是基础提交号，不代表归档完全来自该提交。归档不含 APK、可执行后端 JAR 或已构建 Web，正式应用需要安装环境并从源码构建。首次下载依赖和 Docker 镜像需要网络。

排除以下内容：

- `.git/` 历史、`.workbuddy/` 等本机代理资料、`output/`、`logs/`、临时文件、编辑器配置缓存及本次 `交付包/`。
- `node_modules/`、`.dart_tool/`、`.gradle/`、`.pub-cache/`、`__pycache__/` 等依赖或缓存目录。
- `build/`、`dist/`、`target/`、测试报告输出目录、APK/AAB、编译 class、业务 JAR、运行日志和本机数据库。

- 外置 SkyWalking Agent、Docker 镜像、已有数据库数据卷、已移出的管理端原型及其本机备份。
- 旧源码 ZIP 和其他嵌套压缩包，避免把历史源码重复塞入新归档。

Git 已忽略的文件不会自动收入归档；Git 跟踪但已删除的文件也不会恢复。文件名使用 ZIP 的 UTF-8 标记，可用 Windows 资源管理器或支持 UTF-8 的解压工具打开。确切名单以包内 `source-manifest.json` 为准，该清单不对自身做自引用散列。

## 校验和解压

ZIP 外同时提供 `.zip.sha256` 文件、逐文件清单副本及本说明。先在 PowerShell 中计算：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\小易冰箱-源码-20261110.zip'
```

将结果与同目录 `.zip.sha256` 中的值比较。建议解压到没有中文、空格的短路径，且使用空的目标目录：

```powershell
Expand-Archive -LiteralPath '.\小易冰箱-源码-20261110.zip' -DestinationPath 'C:\Projects'
Set-Location 'C:\Projects\xiaoyi-fridge'
```

不要直接在压缩包窗口运行程序。Linux/macOS 解压时应保留 `android/gradlew` 的可执行权限；ZIP 已记录该权限。

## 从源码运行正式 Web

准备 PowerShell 7、JDK 17、Maven 3.9、Flutter 3.47.8 / Dart 3.13.7、Docker Desktop 和支持 WebGL2 的浏览器；Node.js 22 用于辅助脚本。以下从项目根目录运行，依赖首次启动需要等待健康。

```powershell
docker compose --env-file infra/compose/.env.example `
  -f infra/compose/compose.full.yml up -d `
  nacos mysql-core redis seata skywalking-oap skywalking-ui

# 从源码打包并逐个启动四个正式应用
# 本归档不含 Agent，这一步先运行不带追踪的业务服务
.\scripts\Start-Services.ps1 -WithoutAgent

Push-Location apps/fridge-app
flutter pub get --enforce-lockfile
flutter build web --release --no-pub
Pop-Location
.\scripts\Start-Web.ps1
```

打开 `http://127.0.0.1:3030`，注册账号后创建家庭、添加食材和查看菜谱。该地址属于接收电脑新启动的正式服务，不要求复用原电脑的 18000 隔离预览。新库由 Flyway 初始化，正式菜谱迁移包含 18 道。

需要展示 SkyWalking 链路时，先按 `docs/交付/交付与运行说明.md` 准备 Agent 及 Gateway 插件，再去掉 `-WithoutAgent` 重启应用；业务能启动并不说明追踪已生效。日常不需要启动历史 order/stock。

Android 还需 Android SDK 和设备网络配置，并以接收电脑的真实 API 地址重新构建。当前工程 release 使用模板 debug 签名，不能视为正式发行签名；具体步骤见运行手册。Web 的三维交互与 Android 图片展示方式不同。
