## 第一轮完成定义

- Maven `test` 可从根目录执行并通过。
- Flutter `analyze`、`test` 与 Web release 构建通过。
- Vue 管理端类型检查和生产构建通过。
- `docker compose config` 通过。
- 本地输入格式错误时返回一致的错误结构；有效账号可注册、登录、刷新和退出。
- 登录用户可以创建家庭，并在数据库中看到 `OWNER` 成员关系。
