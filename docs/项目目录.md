# 小易冰箱项目目录与功能范围

更新日期：2026-11-10。按用户确认，以当前已实现的家庭冰箱业务作为作品功能范围。此前设计文档中的扩展设想保留为历史参考，不再作为开发待办。

## 当前功能

| 功能 | 实现位置 | 使用方式 |
| --- | --- | --- |
| 注册、登录、会话刷新与退出 | Flutter `auth`、`auth-family-service`、Gateway | 真实账号及演示浏览入口 |
| 家庭与成员协作 | Flutter `family` / `profile`、`auth-family-service` | 创建、邀请码加入、家庭切换、角色调整、移除成员和转交所有权 |
| 创建家庭及默认冰箱 | `auth-family-service/workspace`、`fridge-service` | 一次创建家庭、OWNER、冰箱、四区与六个容器，跨服务失败回滚 |
| 食材管理与临期查看 | Flutter `fridge`、`fridge-service` | 新增、查询、组合筛选、编辑、移动、使用、丢弃与过期清理 |
| 操作记录及恢复 | 时间线弹层、`food_operation` | 查询流水，对支持的单条操作撤销或恢复 |
| 菜谱与做饭扣减 | Flutter `recipe`、菜谱服务、冰箱服务 | 18 道图文菜谱、库存规则匹配、做饭确认与扣减 |
| 可视化冰箱 | `web/fridge3d`、Flutter 库存清单 | Web 实时三维开门/抽屉交互；Android 厨房参考图及业务表单 |
| 微服务治理 | Gateway、Nacos、Feign、Sentinel、Seata、SkyWalking | 真实家庭初始化流程的发现、鉴权、流控、事务与追踪 |

家庭数据通过重新加载获取；冰箱使用默认分区与容器；临期阈值由服务端 Nacos 统一配置。做饭记录后端接口保留，用户通过操作时间线查看食材扣减。图片随应用打包。

## 本轮清理

- 从有效工程移除 `apps/admin-web` 管理端原型、其专用依赖及 CI 构建任务。原型在本机忽略目录 `output/scope-cleanup-2026-11-10/removed-admin-web/` 留有可恢复备份，不参与构建或交付。
- 从 core/full Compose、示例环境变量和启动输出移除 MinIO 与 RocketMQ；不清理已有容器、数据库或数据卷。
- 家庭页移除推送通知、布局编辑和主题切换相关说明入口及其独立组件，只保留家庭业务和退出确认。
- 实时同步、系统推送、用户独立临期设置、布局编辑、菜谱收藏、独立做饭历史页、Android 实时三维及精细食材素材等扩展能力不再列为开发待办；正式应用没有对应残留路由或空实现需要继续补齐。
- 已完成的后端做饭记录查询、默认布局、服务端临期配置、Web 三维和 Android 图片展示继续保留。独立离线演示中的本地收藏已实现，仍属于演示自身功能。
- `order-service` / `stock-service` 是可运行的历史技术例子，保留源码与契约；需显式使用 `Start-Services.ps1 -IncludeLegacyDemo`。家庭补货只指食材入库。

## 验证与交付边界

功能范围收敛不等于所有平台与部署验收完成。Android 真机、正式签名、硬件 GPU / 多浏览器、持续容量、高可用及新电脑复现仍按实际执行情况记录；现有身份头信任与做饭未知结果重试的限制继续在开发状态及答辩资料中说明。

当前实际预览使用本机 `http://127.0.0.1:18000` 与隔离菜谱服务；原主服务及历史交付压缩包不会因本轮源码清理自动升级。最新结果以 [开发状态](开发状态.md) 和 [本轮审查](reviews/2026-11-10-scope-cleanup.md) 为准。
