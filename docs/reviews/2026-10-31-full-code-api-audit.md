# 全仓代码审查与接口异常复验

日期：2026-10-31。任务：审查当前前后端代码，重点复验接口返回，以及新增食材、菜谱筛选和家庭设置的交互故障。

## 范围与结论

审查覆盖 Flutter 的路由、会话、网络适配、家庭与冰箱控制器、表单和菜谱匹配，Three.js 与 iframe 交互边界，Vue 运营端按钮反馈，7 个后端模块的入口、校验、权限、持久化、公共异常处理和 Gateway，以及 OpenAPI、运行配置和验收脚本。

用户报告的三处问题均有代码原因，新增食材还包含桌面点击穿透和手机底栏遮挡两个独立缺陷。原视觉阶段使用的 Widget 测试与可访问性点击没有覆盖普通鼠标穿过 iframe 的路径；该阶段记录不能代替本轮业务交互验收。本轮增加了普通鼠标、手机完整导航壳及真实接口的复验。

## 发现与修复

| 优先级 | 问题与影响 | 修复及验证 |
| --- | --- | --- |
| P1 | 添加弹层上的鼠标点击被下方三维 iframe 消费，输入框无法填写，反而触发冰箱开合 | 三维输入跟随页面及根导航可见状态暂停，弹层关闭后恢复；普通鼠标已实际保存食材 |
| P1 | 手机弹层使用嵌套导航，保存按钮被底部导航盖住，底栏仍可被点击 | 食材、清单、菜谱和成员弹层统一使用根导航；新增带真实 `HomeShell` 的回归，验证弹层延伸至屏幕底部且场景输入暂停 |
| P1 | “临期优先”无匹配时，筛选按钮随结果一起消失，无法返回全部 | 筛选栏独立于结果渲染；空结果提供“查看全部菜谱”；390/1366 像素 Widget 与真实空家庭浏览器复验 |
| P1 | 退出后的访问令牌仍可通过 Gateway 读取菜谱 | Gateway 对通过签名校验的受保护请求进行撤销状态核验；认证服务故障返回 503，避免误清会话；真实退出验收返回 401 |
| P1 | 多个客户端控制器可能同时轮换同一个刷新令牌；服务端“先查询再撤销”也有并发窗口 | 客户端合并并发刷新并阻止旧刷新覆盖新会话；服务端以条件 UPDATE 原子消费令牌；并发集成测试要求恰有一个 200、一个 401 |
| P1 | 访问令牌续期会重建整个 `GoRouter`，可能丢失当前页面、弹层及未提交内容 | 保持路由实例，监听会话触发重定向；回归验证路由、弹层和输入均保留 |
| P2 | 错误 JSON、路径类型、缺失参数、未知接口和错误方法被兜底处理成 500 | 公共异常处理保留正确的 400/404/405/415，并返回一致 JSON；真实矩阵复验 |
| P2 | 食材数量溢出或小数精度超过数据库能力；过长标签导致 500；逗号标签会被误拆分 | 新增/编辑/使用统一限制 9 位整数、3 位小数及最小 0.001；标签限制分隔符、单项和存储总长度；非法请求返回 400 |
| P2 | 新增数量可输入 NaN/Infinity，日期按时间比较会误拒绝同一天 | 前端拒绝非有限数、过量精度和超长字段；日期统一为日期零点；日期选择返回后检查组件存活 |
| P2 | 写入已成功但库存重新读取失败时，表单仍等待或提示写入失败，可能导致重复添加 | 写入成功独立完成，刷新由工作区加载/错误态处理；回归验证只写一次、刷新可单独重试 |
| P2 | 家庭设置是带箭头的静态行，提醒开关不可操作；创建/加入输入无效时没有反馈 | 设置项可打开功能说明或真实布局；未实现的推送与布局编辑明确说明；家庭表单增加校验、忙状态、错误保留与重试 |
| P2 | 过期或已耗尽的食材仍计入菜谱覆盖率和临期推荐 | 匹配仅使用数量为正且未过期的记录；补充重复名称中有效记录的回归 |
| P2 | UTF-8 密码可能在字符数量合法时超过 BCrypt 字节限制，产生 500 | 注册和登录都校验 72 字节上限，客户端注册提示一致；真实矩阵与集成测试覆盖 |
| P2 | 本地关闭 Nacos 时 Gateway 仍采用服务发现地址 | 增加完整 `application-local.yml` 直连路由；cloud 保持服务发现；路由绑定专项测试通过 |
| P2 | 家庭权限服务返回空或异常结构时可能发生空指针；前端错误元数据类型不符可能触发强转错误 | 检查上游响应结构并返回 503；API 客户端安全读取错误字段并显示字段级校验信息；专项测试覆盖 |
| P2 | 浏览器可能混用旧主程序和新页面资源 | 启动脚本内嵌到入口页，主程序携带本次构建标识；浏览器已核对实际入口版本 |
| P3 | 外部请求 ID 可含引号等内容，影响错误 JSON 和跟踪 | Gateway/Servlet 限制请求 ID 格式和长度，否则生成 UUID；回归覆盖 |
| P3 | 运营端部分演示按钮没有点击处理 | 增加明确的功能未接入提示；未将演示按钮宣称为真实业务功能 |
