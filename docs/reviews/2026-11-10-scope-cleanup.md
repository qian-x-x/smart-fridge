# 当前功能范围收敛与目录清理审查

日期：2026-11-10。

用户确认当前作品功能已够用，要求剔除其他未完成功能并更新目录。本轮以已实现的家庭食材业务为范围，取消原扩展计划。

## 审查范围及处理

- 审查清理前开发状态、根目录 README、正式 Flutter 入口及现有家庭页测试、CI、core/full Compose、示例环境变量、启动脚本、运行和交付说明，以及代码对待清理模块的引用。
- 正式应用移除家庭页的临期推送、布局及主题能力说明入口、对应只读说明弹层和专用组件；家庭区占满原内容区域，账号退出及其确认保留。食材页面临期标识、默认分区、Web 三维及系统可访问性行为保留。
- 移出 `apps/admin-web` 静态原型，共 29 个 Git 跟踪文件；移除该应用独立的 npm 依赖树、构建目录及 CI job。自动审查拒绝递归删除命令，未执行该删除；改为将已核对的整个目录可恢复地移到本机忽略目录 `output/scope-cleanup-2026-11-10/removed-admin-web/`，不参与构建或源码交付。
- 从 Compose 删除未接入业务的 MinIO 和 RocketMQ 服务、其卷声明及示例凭据；移除启动脚本的对应地址输出。没有运行 Compose up/down/remove-orphans，没有删除已有容器、镜像、数据库或数据卷；原本机 `.env` 不改动。
- 取消实时同步、个人临期设置、布局编辑、菜谱收藏、独立做饭历史页、Android 实时三维及精细食材素材的开发计划。这些扩展没有正式实现或空路由需要删除；后端已实现的做饭历史查询、全局临期配置和独立离线演示中的本地收藏继续保留。
- order/stock 已完成历史技术验证，本轮保留源码、契约与显式启动方式，不扩大清理至已完成功能。
- 更新 README、[项目目录](../项目目录.md)、运行及交付说明、历史需求文档提示、[答辩源稿](../答辩/小易冰箱技术使用说明与答辩问答.md)与 Word；开发状态将当前功能范围与旧阶段计划区分。

清理前工作区已经有 V2.0 UI、18 道菜谱、离线演示和答辩文档的未提交改动。本轮保留它们。核对全部新增清理差异及涉及文件的完整内容，逐个确认删除的管理端文件及其引用；其余既有跟踪差异以清理前快照比较。完整工作区与本轮增量快照保存在忽略目录 `output/scope-cleanup-2026-11-10/`。
