本文件作为 V1.4 说明之上的当前视觉/交互补充。家庭权限、库存、数量精度、版本冲突及接口规则沿用工程契约；历史 Word 文档与三版选稿保留。

## 品牌与基础样式

- 名称：小易冰箱；英文辅助名：XIAOYI FRIDGE。
- 口号：查食材，看菜谱，都容易。
- 配色：奶油背景 `#FCF5E9`，纸白卡片，陶土橙 `#BC4D30`，可可文字 `#442B22`，暖灰文字 `#806A5C`，亚麻底 `#F6E6D5`，边框 `#ECDFCF`；成功/库存使用鼠尾草绿，过期使用深红，并配文字。
- 卡片/弹层采用较大圆角，主次按钮采用胶囊形，正文以可读性优先。Flutter 内置 Xiaoyi UI 常用中文字库，附源字体 OFL 许可证；未覆盖字符可使用平台回退。
- 名称用于启动、登录/注册、页面品牌、Web/PWA、Android 安装标签及运营端。工程包名和 API 标识继续兼容既有项目。

## 导航与按钮

主导航保留独立分支，切换不重建三维 iframe，保留页面查询/滚动。切入动画约 310 ms，轻微上移和淡入；非活动页面关闭焦点、ticker 和模型输入/渲染，退出登录销毁分支。弹层打开期间暂停场景交互，避免穿透。

按钮悬停调整色彩/阴影，按下约 120 ms 缩至 97%，保持命中范围和焦点语义。系统减少动态效果时取消或缩短动画。提交中锁定写入口，成功后显示反馈，失败保留输入及错误。只读和演示写入口禁用并说明原因。邀请码实际复制，丢弃二次确认；没有撤销入口时明确说明。

食材使用数量支持加减和手填，范围为 0.001 至当前库存，最多三位小数，写入携带原版本。新增表单检测实际值变化，聚焦/选中文字不触发误报；成功保存正常关闭。

## 实现边界与验收

登录照片与非 Web 厨房参考图是视觉素材。Web 继续使用可交互的真实几何模型，并随家庭完整库存同步。照片、实际三维和演示数据应按用途区分。

运营端仍是演示；推送、主题切换、布局编辑、做饭扣减与时间线没有随此次改版落地。当前用户端真实数据继续使用已有 API。
