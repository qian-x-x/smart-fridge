## 重新启动本机预览

以下在仓库根执行。先确保原本机 Docker 开发依赖、auth/fridge 服务正常；本轮已运行的新网关/菜谱容器无需反复重建。

```powershell
# 仅在隔离验收服务尚未运行时；使用本机开发配置和新的 recipe_ui_* schema
pwsh -NoProfile -File scripts/Start-QuietWhiteAcceptance.ps1
# 使用已构建的 apps/fridge-app/build/web，保持此进程运行
node scripts/preview-quiet-white.mjs
```

预览仅监听 127.0.0.1:18000；其 API 代理至 18080，再访问隔离菜谱服务 18083。原运行入口 3000/3030、原菜谱服务 8083 没有替换；它们不能作为本轮 18 道目录的预览地址。没有公开部署或对外监听。
